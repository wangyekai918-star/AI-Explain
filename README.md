## 最容易混淆的五条规则

1. 用户说的“大窗/全屏”在本版本指展开聊天面板，**没有实现浏览器全屏或铺满屏幕**。
2. 多段回答属于一次连续播放任务。暂停不拆任务，切段不归零；新追问或切换历史回答才切任务。
3. 底部播放、暂停、倍速和进度定位控制当前任务。回答结束后，未完成的原讲解自动从断点恢复；已完成则保留回答结束进度。
4. Demo 是模拟会话和预设内容。能运行不等于真实 AI、TTS、ASR 和业务权限已经联调通过。
5. PRD 的平台目标、当前代码能力和后续规划分别标注，不能把产品规划当作已上线功能。

## 文档依据与冲突处理

本套说明综合了原始 PRD、开发指南、服务接口说明，以及本轮已确认的交互调整，并核对当前 `core/`、`ui/`、`demo/` 和测试。

- **当前行为事实**以本版本代码为依据；代码与期望不一致时必须记录差异，不能默认代码天然正确。
- **已确认的产品调整**构成本版本新增规则，例如连续回答时间轴、点击录音、模式记忆和 IP 分层。
- **历史描述**中的按住说话、回答独立组头按钮、回答暂停后主播放键回主轨、自动折叠回答及旧双产物构建方式，不应继续指导当前 UI。
- **平台规划**中的多格式解析、S1/S2 复用、S3 每次生成、场景自动校验和业务能力调用，需要对应平台服务与版本证据。
- 原始内部文件未放入本公开仓库；服务地址、鉴权配置和真实数据在受控环境交接。

本地工程集成和部署规则见交付说明；本仓库本身没有 `npm install`、在线 Demo 或源码下载承诺。
