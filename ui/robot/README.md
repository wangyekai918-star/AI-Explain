# IP 形象动画

当前 H5 只加载 8 类动作：待机、无聊、睡觉、醒来、收到、等待转动、播报音波、失败。形象基于用户上下层切图；眼部几何参考 Agent Robot Avatar，保留 MIT 许可。

## 行为

- 空闲时每隔 6～12 秒随机选择待机、无聊或睡觉；睡着后保持 4.5～8 秒，再播放醒来。醒来只从睡眠进入，避免闭眼直接跳成睁眼。
- 播报、录音、识别与思考过程中停止随机动作；空闲计时器在新请求及卸载时清理。
- 用户提交文字/语音问题后先播放收到；随后转为等待转动。若结果很快到达，播完收到后直接进入播报或失败。
- 等待转动时两眼为圆形；退出思考时连续恢复竖椭圆。
- 生成成功后播放播报音波，暂停或结束回待机。新错误或刷新失败播放失败，再回待机；同一个错误不会被进度快照重复触发。
- 所有形状、位置与眼睑从当前显示值过渡，不插入重置帧。眼睑使用透明 SVG 遮罩，不画黑色矩形。
- 新动作会取消旧动作的完成回调，不影响新的请求状态。

`useRobotVisualState.ts` 只订阅控制器快照，不修改业务请求或播放器逻辑。`RobotAvatar.vue` 管理随机空闲循环与动画完成事件，内联样式适配 Vue 自定义元素 Shadow DOM。

`eyes-adapter.js` 是精简眼部引擎源码，不包含穿梭、波浪、爱心、随机抽取等未使用的动画。运行 `node ui/robot/build-eye-engine.mjs` 可同步生成内嵌引擎 `eyes-engine.html`。所有切图和代码本地加载，无 CDN 请求。

- 主讲解或回答实际播放时循环五根圆角音柱的播报音波，加载完成直接衔接音波，不播放成功动作；暂停、结束后恢复待机，思考仍使用纯圆等待转动。

- 播报音波为播放状态驱动的节奏动画，不是 TTS 音频振幅采样；与椭圆眼睛透明渐变衔接。
